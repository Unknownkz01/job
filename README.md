# GK Development

Статический сайт команды разработки. Готовые файлы находятся в `dist` и не требуют сборки.

## Локальный запуск

```sh
python -m http.server 8080 --directory dist
```

Откройте http://localhost:8080.

## Содержание и заявки

- `dist/config/content.js` — проекты, команда, услуги и цены. После изменения выполните `npm run build`, чтобы обновить HTML.
- `dist/config/contact.js` — номер WhatsApp в международном формате и адрес обработчика заявок.
- Обработчик принимает POST с JSON и возвращает успешный HTTP-статус только после приёма заявки. Проверку данных, ограничение запросов и хранение обращений нужно реализовать на сервере.
- Если задан только WhatsApp, форма открывает подготовленное сообщение: посетитель отправляет его самостоятельно.
- Пока контакты не настроены, форма позволяет скачать описание проекта в текстовом файле и прямо сообщает, что заявка не отправлена.

Перед публикацией добавьте реальные контакты и правила обработки персональных данных. После выбора основного домена настройте canonical, og:url и sitemap.xml. Внешние сервисы и серверный обработчик в репозиторий не входят.

## Проверка

```sh
npm install
npx playwright install chromium
npm test
```

Проверяются мобильная навигация, отсутствие горизонтального переполнения, валидация формы, скачивание описания, отправка и ошибки API, переход в WhatsApp и доступность контента без JavaScript.
